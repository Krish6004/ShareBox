# 📦 ShareBox — Frontend Client

Official modern React client for **ShareBox** (*Share Files. Instantly.*).

## 🚀 Tech Stack
- **Framework**: React 19 + Vite 7
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism System
- **Animation**: Framer Motion 12 Spring Dynamics
- **Icons**: Lucide React
- **HTTP Client**: Axios

## 🛠️ Development
```bash
npm install
npm run dev
```

## 📦 Production Build
```bash
npm run build
npm run preview
```
